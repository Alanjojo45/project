# HomeService Download Portal

Welcome to the official download landing page and release portal for the **Home Service Booking and Management System**.

## 🚀 Live Webpage
Open `index.html` in any modern web browser or serve it with any static web server (such as GitHub Pages).

## 📦 What's Included
- **`index.html`**: Responsive landing page with dark-mode aesthetic, live download links, and full documentation.
- **`preview.jpg`**: High-resolution interface preview of the application.
- **`open_page.bat`**: Quick launcher to open the download page locally.
- **`.gitignore`**: Excludes heavy 50MB+ compiled binaries (`.exe` and `.zip`) to keep the Git history lightweight.

## 📥 Downloading the Installer
The installer (`HomeServiceSetup.exe`) and portable package (`HomeService-Windows.zip`) can be downloaded directly from the [GitHub Releases](https://github.com/Alanjojo45/project/releases) section.
